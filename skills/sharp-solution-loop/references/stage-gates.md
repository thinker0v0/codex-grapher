# Stage Gates

## Problem approved

- The target actor, costly problem, causal mechanism, constraints, non-goals,
  baseline, and falsifiable success measure are explicit.
- Evidence can disprove the problem. Unresolved high-impact assumptions are
  listed rather than hidden.

## Research approved

- Decision-critical claims have traceable sources and dates.
- Primary sources are preferred; conflicts, uncertainty, freshness, privacy,
  license, and point-in-time requirements are recorded.

## Solution approved

- At least two credible alternatives were compared.
- The chosen mechanism addresses the root problem within constraints.
- Failure modes, economics, moat hypothesis, validation plan, and stop/pivot
  conditions are explicit.

## Scaffold approved

- A new agent can find inputs, outputs, ownership, allowed tools, tests, state,
  budgets, timeouts, evidence, and escalation paths without conversation history.
- Builder and evaluator are independent.

## Implementation ready

- `HANDOFF.md` contains only current approved decisions and exact acceptance
  commands. It links to source artifacts instead of duplicating uncertain facts.
- The repository is clean or unrelated changes are identified and preserved.

## Release candidate

- Representative real or production-like data passed in a safe environment.
- Required tests, adverse cases, rollback/recovery, security, and independent
  evaluation passed with machine evidence tied to a Git SHA.
- Human taste and consequential-action approval remain outside the agent loop.
